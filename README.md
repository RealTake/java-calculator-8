# java-calculator-precourse

# 기능 목록

- ## 1. 문자열 입력
    - "덧셈할 문자열을 입력해 주세요."의 안내 메세지와 함께 문자열을 입력 받는다.
- ## 2. 입력 문자열에서 양수 데이터를 구분자를 통해 분리
    - 기본 구분자를 통한 데이터 분리
    - 커스텀 구분자를 인식하여 데이터 분리
- ## 3. 입력된 데이터의 양수 검증
    - 양수 validator 추가
- ## 4. 입력된 양수를 모두 더한 값을 계산하여 결과 출력
    - "결과 : %d"의 형태로 결과 값을 출력

---

# 코멘트

- ## 숫자형 원시 타입을 쓰지않고 BigDecimal을 사용한 이유
    - 기능 요구사항에서 정수/실수 구분 및 값의 범위가 명확히 정의되지 않아, 소수점 입력과 큰 수 연산에 대비하기 위해 BigDecimal을 사용함.
    - BigDecimal은 연산 속도 면에서는 다소 불리하지만, 과제가 덧셈'계산기'임을 고려해 핵심 가치인 정밀도와 안정성을 확보하기 위해 트레이드오프를 감수함.
